# Rover project page media

Original video assets for [Rover: Interaction-Centric Camera-Controlled Video Generation](https://chaoyuesong.github.io/interaction_centric_results/).

This repository is owned by the same GitHub account as the project page. Videos are referenced at a fixed commit and do not depend on any other project page.

The six 4D reconstruction videos are the original 1920 × 1080, 30 FPS, 450-frame (15-second) MP4 files. They have not been re-encoded. File sizes and SHA-256 checksums are recorded in `manifest.json`.
